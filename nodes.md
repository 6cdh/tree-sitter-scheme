## Nodes

This page contains all visible nodes in yaml format.

```yaml
- comment
- boolean
- character
- string
- escape_sequence # `\"` or `\\` in a string
- number
- symbol # R5RS identifier

- list # () list; may contain `dot`
- dot # `.` inside a list
- quote # '
- quasiquote # `
- unquote # ,
- unquote_splicing # ,@

- vector
```
